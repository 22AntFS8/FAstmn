🔐 FastPass

FastPass — десктопный менеджер паролей, разработанный на C# с использованием WPF.
Приложение предназначено для безопасного хранения, управления и быстрого доступа к учетным данным пользователя.


✨ Возможности

🔑 Хранение логинов и паролей

🔒 Защита данных мастер-паролем

➕ Добавление новых учетных записей

✏️ Редактирование сохраненных записей

🗑️ Удаление записей

🔎 Поиск по сохраненным аккаунтам

🎲 Генерация надежных паролей

📋 Копирование логина и пароля в буфер обмена

🏷️ Группировка записей по категориям

💾 Локальное хранение данных

🛡️ Шифрование конфиденциальной информации

🛠️ Технологический стек

Безопасность

В проекте планируется использовать современные криптографические механизмы для защиты пользовательских данных:
хеширование мастер-пароля;
симметричное шифрование хранилища;
безопасная генерация случайных паролей;
защита конфиденциальных данных от хранения в открытом виде.
Конкретные алгоритмы и параметры шифрования могут изменяться в процессе разработки.

🔐 Принцип работы

После запуска пользователь проходит аутентификацию с помощью мастер-пароля.

│      FastPass       │

Данные хранилища не должны сохраняться в открытом виде. После успешной аутентификации приложение расшифровывает необходимые данные и предоставляет пользователю доступ к ним.

🔒 Безопасность

FastPass предназначен для работы с чувствительными данными, поэтому безопасность является одним из основных аспектов проекта.

В частности, необходимо избегать:

хранения мастер-пароля в открытом виде;

хранения паролей пользователей в обычном текстовом файле;

использования предсказуемого генератора случайных чисел для паролей;

записи секретных данных в логи;

передачи паролей через небезопасные механизмы.

Важно: текущая версия проекта не должна рассматриваться как готовое средство защиты реальных критически важных паролей до проведения полноценного аудита безопасности.


FastPass является учебным/пет-проектом, целью которого является изучение:

C#;

WPF;

MVVM;

работы с локальными данными;

криптографии;

проектирования пользовательских интерфейсов;

принципов безопасной разработки.
